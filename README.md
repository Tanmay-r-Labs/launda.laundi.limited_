# 🏫 BOMIS Sambalpur • Class 7 & 8 Syndicate

Official Instagram bio website for the 7 legends of **Birla Open Minds International School (BOMIS), Sambalpur**.

---

## 🚀 How to Publish on GitHub (100% Free Live URL for Instagram Bio)

Follow these 4 simple steps to make the site live on the internet so you and your friends can put the link in your Instagram bio:

### Step 1: Create a GitHub Repository
1. Log in to [github.com](https://github.com) (or create a free account if you don't have one).
2. Click the green **"New"** button to create a new repository.
3. Name it: `bomis-squad` (or any name you like).
4. Select **Public**.
5. Click **"Create repository"**.

### Step 2: Upload Files
1. On your new repository page, click **"uploading an existing file"** (or use Git CLI if you prefer).
2. Drag and drop all the files from this folder (`index.html`, `README.md`, `.gitignore`) into GitHub.
3. Click the green **"Commit changes"** button at the bottom.

### Step 3: Turn on GitHub Pages (Free Hosting)
1. In your repository, go to **Settings** (top menu tab).
2. On the left sidebar, click **"Pages"**.
3. Under **Build and deployment > Branch**:
   - Change `None` to **`main`** (or `master`).
   - Leave the folder as `/ (root)`.
4. Click **"Save"**.

### Step 4: Get Your Bio Link!
1. Wait 30 to 60 seconds and refresh the page.
2. A green banner will show your live website link:
   👉 `https://<your-username>.github.io/bomis-squad/`
3. Copy this link and paste it into everyone's Instagram bio!

## 🛠️ How to Update Photos, Real Handles & Achievements
Whenever you want to add new photos, real Instagram handles, or add new medals won at school:
1. Open `index.html` in Notepad or VS Code.
2. Scroll to line ~260 (`<script>` section).
3. Update the `friends` list or `achievements` list.
4. Save and commit to GitHub — the live site updates automatically!
