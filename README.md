# launda.laundi.limited_ • BOMIS Sambalpur

Website for the 7 friends at **Birla Open Minds International School, Sambalpur**.

## 📁 Folder Structure
- `index.html` — Mobile + desktop website.
- `assets/group.jpg` — Group cover photo.
- `assets/photos/` — Individual photos (`tanmay.jpg`, `tanvi.jpg`, `tejas.jpg`, `pranjal.jpg`, `suryansh.jpg`, `prakruti.jpg`, `aarav.jpg`).
- `assets/memories/` — Garba Night & Van Gupchup photos/videos.
- `assets/hall-of-fame/` — Photos & videos for Hall of Fame achievements.

## 🚀 Publishing on GitHub Pages
1. Upload/push all files in this folder to `Tanmay-r-Labs/launda.laundi.limited_`.
2. In **Settings > Pages > Branch**, make sure **`main`** and `/ (root)` are selected.
3. Live link: `https://tanmay-r-labs.github.io/launda.laundi.limited_/`
